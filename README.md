### 🏗️ Data & Modeling Approach

The dashboard uses an Excel-based analytical workflow combining **Power Query, Data Model relationships, PivotTables, and dashboard formulas**.

**Power Query**
- Prepared and loaded the analytical tables used in the workbook
- Structured separate fact and dimension tables for analysis

**Data Model**
- `FACT_SHIPMENT`
- `FACT_INVENTORY`
- `DIM_DATE`
- `DIM_HUB`
- `ROUTE_MASTER`
- Relationships connect the fact tables with the relevant dimension tables to support cross-table analysis

**Reporting Layer**
- PivotTables for KPI and performance analysis
- `GETPIVOTDATA` for dashboard KPI retrieval
- Excel formulas and dashboard layout for presentation

🔧 **Excel | Power Query | Data Model | Table Relationships | PivotTables | GETPIVOTDATA | Excel Formulas | Dashboard Design | Data Visualization**

> An operational analytics project that combines structured data preparation, relational modeling, and Excel-based reporting to bring shipment, hub, and inventory KPIs into a single dashboard view.
